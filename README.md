## About

I am an MSc student in Artificial Intelligence & Machine Learning at Christ University with a strong interest in building practical, secure, and scalable systems that combine ML with decentralized technologies. I enjoy end-to-end development — from prototyping models and smart contracts to deploying full-stack applications.

**Focus areas:** AI/ML model development, secure smart contracts (Solidity & Foundry), and Web3 integrations using ethers.js.

## What I Do

- Design and train ML models using Python (PyTorch / TensorFlow) for real-world tasks.
- Write, test and deploy smart contracts using Solidity and Foundry.
- Build web interfaces and integrations with Web3 stacks (React, ethers.js).
- Rapid prototyping, reproducible experiments, and developer-friendly tooling.
